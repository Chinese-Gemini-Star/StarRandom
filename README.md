# StarRandom

## 项目信息

此项目曾运行在[https://random.geministar.site/](https://random.geministar.site/),目前服务器和域名暂未续费.

一个简易的随机数生成平台

可以自定义随机数的上限和下限、数量以及是否可重.

## 项目结构

* `/cmd` 各微服务的main文件
* `/internal/controller` 接口定义,包括函数形式和结构体形式
* `/internal/model` 数据对象
* `/internal/router` 路由定义
